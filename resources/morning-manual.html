Morning Meeting Culture Lab04

Morning Meeting Overview

A Rehearsal,
Not A Discussion

Fifteen minutes. Six moves. A fixed order that never changes. The predictability is the therapeutic ingredient — students know what comes next, which lowers anxiety and raises participation.

Observation & Fidelity

See It · Name It · Build It

See It

Capture a real, observable strength using the Observation Tool — not a vague impression.

Name It

Describe the strength precisely. Specific feedback expands; vague feedback stalls.

Build It

Rehearse the expanded move together so it becomes the teacher's default.
